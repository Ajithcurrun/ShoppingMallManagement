# Shopping Mall Management System

A backend application developed using Spring Boot and PostgreSQL for managing
shopping mall operations.

## Technologies Used

- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Postman
- Maven

## Modules

- Shop Management
- Employee Management
- Item Management
- Customer Management

## CRUD Operations

The application provides REST APIs for:

- Create
- Read
- Update
- Delete

## Architecture

Postman
↓
Controller
↓
Service
↓
Repository
↓
JPA / Hibernate
↓
PostgreSQL
